# Codex Instructions — SocialBoost AI

Before doing any work in this repository:

1. Read the root `master.md` completely. It is the authoritative project rulebook.
2. Read the relevant approved documents in `docs/`.
3. Follow the current phase and task in `master.md`.
4. Do not go outside the approved SocialBoost AI scope or current phase.
5. Do not invent features, architecture, dependencies, apps, tables, endpoints, or infrastructure.
6. Inspect existing files and Git status before changing anything.
7. Never overwrite user work, expose secrets, or run destructive commands.
8. Do not install dependencies, apply migrations, commit, push, or deploy unless the task explicitly authorizes it.
9. For consequential changes, explain the proposed files and plan before implementation.
10. Run relevant tests when implementation is authorized and report actual results.
11. At task completion, summarize changed files, commands, tests, migrations, and remaining issues.
12. Stop after the requested task. Wait for the project owner's next instruction.

If instructions conflict or requirements are unclear, stop and ask for clarification. Do not silently make a consequential assumption.
